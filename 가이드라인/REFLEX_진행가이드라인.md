### 0-3. 연구 분야로서의 정체성 (중요)

연구분야의 "자주 하는 실수"는 결과물이 AI 요약문에 그치는 경우입니다. 그래서 **연구 질문과 결론은 팀이 세우고**, 펫은 결과를 보여주는 도구로만 씁니다.

- **RQ1.** APL 뉴런의 억제 강도를 낮추면, 처음 학습은 유지되면서 **조건이 바뀐 뒤 다시 배우는 학습(역전학습)**만 느려지는가?
- **RQ2.** 그 차이는 자극 A·B에 반응하는 KC(케년세포) 집합이 **더 많이 겹치게 되는 것**으로 설명되는가?
- 가설 근거: Wu et al. 2012(APL의 GABA를 줄이면 역전학습이 손상됨), Lin et al. 2014(APL 피드백이 KC 반응을 드문드문하게 유지하고, 끊으면 비슷한 냄새를 구별하지 못함). 출처는 10장에 있습니다.

## 1. 처음 보는 사람을 위한 배경 설명 (10분이면 읽습니다)

### 1-1. 초파리 "버섯체(Mushroom Body, MB)" 학습 회로

```
 냄새/자극 A·B                         보상·벌 신호
      │                                    │
   [PN] 투사뉴런 (안테나엽 → 버섯체)      [DAN] 도파민 뉴런 (PAM=보상, PPL1=벌)
      │  ← FlyWire 실제 연결                │  KC→MBON 연결 강도를 바꿈 (학습)
      ▼                                    ▼
   [KC] 케년세포 약 2,000개/반구 ───────▶ [MBON] 출력 뉴런 (접근 쪽 / 회피 쪽)
      ▲   │                                  │
      │   ▼                                  ▼
   [APL] 1개/반구, GABA 억제              선택: A로 갈까, B로 갈까
   (KC가 활발해지면 APL이 KC 전체를 눌러서 소수만 반응하게 함)
```

- **KC**: 자극마다 일부만 반응합니다(약 5~10%). 반응하는 KC 집합이 그 자극의 "코드"입니다.
- **APL**: KC를 전체적으로 억제해서 코드를 드문드문하고 덜 겹치게 만듭니다. 계획서의 **"학습 부위의 반응을 줄여주는 특정 신경세포"가 바로 APL**입니다.
- **DAN → KC→MBON 연결 약화**: 보상을 받으면 "회피 MBON"으로 가는 연결이 약해져서 그 자극에 더 다가가게 됩니다(Hige et al. 2015 등의 시냅스 약화 원리).
- **역전학습**: 처음에는 A가 정답, 나중에는 B가 정답. 예전 기억을 눌러야 새 기억이 이깁니다.

### 1-2. 계획서 용어를 연구 용어로 옮기면

| 계획서 표현 | 연구 용어 | 코드 변수 예시 |
|---|---|---|
| 서로 다르게 구분되는 두 입력 신호 A·B | PN 활성 패턴 A, B | `pn_A`, `pn_B` |
| 학습 부위 | 버섯체 KC | `kc` |
| 반응을 줄여주는 특정 신경세포 | APL (GABA성 피드백 억제) | `g_apl` |
| 작용을 약하게 한다 (삭제는 하지 않음) | APL→KC 가중치에 배율 0.2 등을 곱함 | `g_apl=0.2` |
| 학습 기능을 끈 상태 | 학습률 0 (음성 대조군) | `eta=0` |
| 좋은 결과 / 좋지 않은 결과 | 보상(PAM) / 벌(PPL1) 신호 | `reward=+1/-1` |
| 다시 배우는 과정 | 역전학습 (reversal learning) | `reverse_at` |
| 두 자극에 반응하는 신경세포 수와 겹침 | KC 희소도(sparseness), 표상 겹침(Jaccard) | `sparseness`, `overlap` |

### 1-3. 전체 시스템 구조 (PoC)

```
[사용자 말]──▶ ① AI 명령 변환(LLM) ──▶ ② 허용목록 검사(규칙) ──▶ ③ 신경망 실험 엔진(Python)
                                                                   │ 선택·학습은 여기서만 계산
[펫 화면]◀── ⑤ 숫자 근거 검사(규칙) ◀── ④ AI 상태 설명(LLM) ◀── 상태 JSON (MBON 반응, 선택, 최근 경험)
```

- **AI가 하는 일**: ①, ④ 두 군데뿐입니다. 행동 선택과 학습은 신경망과 고정된 규칙이 맡습니다(계획서 4-③).
- **보안 전공의 몫**: ②, ⑤. AI 출력도 믿지 않고 다시 검사합니다. 프롬프트 인젝션 같은 공격 입력 테스트도 여기에 포함됩니다.
- **본 비교 실험(30회 반복)에는 LLM을 넣지 않습니다.** 고정된 입력 스크립트로 돌려서, AI 응답의 차이가 실험 조건에 섞이지 않게 합니다(계획서 4-④).

### 5-2. "AI 덕분에 수월해졌다"를 숫자로 보여주기

가이드라인의 개선 사례처럼 "몇 건 중 몇 건, 몇 시간에서 몇 시간"으로 적습니다.

| 작업 | 기존 방식의 어려움 | AI 사용 후 | 측정치 (팀이 기록) | 사람의 검증 |
|---|---|---|---|---|
| 연결체 데이터 처리 | 대용량 표 구조를 몰라서 코드 작성에 며칠이 걸림 | 초안 코드를 받아 수정 | 작성 시간 ○시간 → ○시간, 오류 ○건 발견 | 뉴런 수 문헌 대조 |
| 문헌 검토 | 영문 신경과학 논문을 이해하기 어려움 | 원문 기반 요약표 | 논문 ○편 정리, AI 오류 ○건 | 원문 그림·표 대조 |
| 자연어 명령 | 규칙 기반 파서는 다양한 표현에 약함 | LLM 파서 + 허용목록 | 정확도 규칙 ○% vs AI ○%, 공격 차단 ○/20 | 검사 사례 40개 이상 |
| 상태 설명 | 고정 문구만 가능 | 상태 JSON 기반 자연어 설명 | 근거 일치율 ○%, 검사기 교체 ○건 | 숫자 검사기 + 수기 확인 |
| 검사 사례 생성 | 공격 입력을 떠올리기 어려움 | 후보 50개 생성 | 채택 20 / 기각 30 (이유 기록) | 팀 선별 |

> 주의: 측정치는 실제로 잰 값만 씁니다. 추정이면 "추정"이라고 적습니다. 부풀리면 감점입니다.

## 6. 실험 설계 상세

### 6-1. 조건
| 조건 | `g_apl` | `eta` | 목적 |
|---|---|---|---|
| 기본 | 1.0 | 기준값 | 기준 |
| 학습 끔 | 1.0 | 0 | 음성 대조: 학습 없이는 선택이 우연 수준인지 |
| APL 약화 | 0.2 (예비 실행으로 결정) | 기준값 | 핵심 비교 |
| (선택) APL 약화 단계 | 0.5, 0.2, 0.05 | 기준값 | 강도에 따라 결과가 단계적으로 달라지는지 |

- APL은 **삭제하지 않고** APL→KC 억제 강도에만 배율을 곱합니다(계획서 4-②).
- 같은 seed는 조건이 달라도 같은 초기 상태와 같은 무작위 순서를 씁니다(대응 비교).

### 6-2. 사전에 고정할 것 (`prereg_v1.yaml`)
시도 수, 보상·벌 값, `g_apl` 값, 선택 규칙(`beta`), 학습 완료 기준, 지표, 통계 방법, seed 목록. 바꿔야 하면 `prereg_v2.yaml`을 새로 만들고, **바꾼 이유와 날짜**를 기록합니다. v1 결과도 지우지 않습니다.

### 6-3. 지표
- 첫 학습·역전학습의 **학습 완료 시도 수** (완료하지 못하면 "실패"로 별도 집계)
- 역전 전후 A 선택 비율
- KC 활성 비율(희소도), A·B KC 집합의 Jaccard 겹침
- KC→MBON 가중치 변화량
- (LLM) 명령 정확도, 공격 차단율, 설명 근거 일치율

## 9. 모델 설계 메모 (지도교수 검토용)

- **뉴런 모델**: 발화율(rate) 모델. KC 활동은 `max(입력 - 문턱 - APL억제, 0)`로 계산하고, APL 억제는 KC 전체 활동에 비례하는 피드백의 안정 상태로 구합니다(starter 코드는 이분탐색 사용). 전뇌 LIF(Brian2) 모델은 추가 과제입니다.
- **학습 규칙**: 보상이면 활성 KC→회피 MBON 가중치를 약화하고, 벌이면 활성 KC→접근 MBON 가중치를 약화합니다. 시간이 지나면 기준값으로 천천히 회복합니다(망각). 이 규칙의 근거 문헌과 단순화한 점을 보고서에 명시합니다.
- **선택 규칙**: 가치 v = (접근 − 회피 MBON 반응)을 활성 KC 크기로 정규화하고, 시그모이드 함수로 A 선택 확률을 계산합니다.
- **장난감 모델에서 이미 확인한 함정** (보드섹션 사례로 사용 가능):
  1. 망각 항이 없으면 역전학습이 아예 불가능했습니다(첫 버전에서는 모든 seed가 실패).
  2. APL 억제를 반복 갱신으로 계산하면 KC 값이 0에 수렴하지 않아 활성 비율이 부풀려졌습니다. 그래서 안정 상태를 직접 구하는 방식으로 고쳤습니다.
  3. 학습 완료 기준이 느슨하면 학습을 끈 대조군도 통과했습니다.
