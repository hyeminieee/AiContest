# REFLEX PoC 시연 프로그램

초파리 버섯체 회로(PN → KC ⇄ APL → MBON)로 펫이 A·B 중 하나를 고르며 배우고, 조건이 바뀌면 다시 배우는 과정을 **7단계로 실행하며 결과를 보여주는** 웹 화면입니다.

> 기본 회로는 FlyWire v783 오른쪽 반구에서 추출한 실제 연결입니다(`data/processed/`). 입력 A·B는 DM2·DM4(우선 검증 후보, 팀 확정 전)이고, 판정 기준(정답 확률 0.8 이상 5회 연속)과 APL 약화 정도(0.2배)는 임시값입니다. 예전 무작위 연결은 `--circuit toy`로 비교용으로만 씁니다.
>
> 반복 실험만 따로 돌리려면 `python poc/engine.py --n 30 --start 0 --tag pilot`을 실행합니다. 시도별 원자료(`_trials.csv`), 실행별 결과(`_runs.csv`), 요약과 설정(`_summary.json`)이 `poc/results/`에 저장됩니다. 예비 실행과 본 실험은 서로 다른 `--start` 범위를 씁니다.

## 3D 펫 화면: REFLEX_Pet.html

`poc/REFLEX_Pet.html`을 더블클릭하면 three.js 3D 생활 공간에서 펫을 훈련하고(훈련 탭), 부모를 골라 교배하고(교배 탭), 네 성향 조합을 비교(비교 탭)할 수 있습니다. 인터넷 연결 없이 열립니다(three.js 0.160.0을 파일 안에 넣음, `vendor/three/`, MIT).

- 선택·학습은 `static/local_engine.js`(파이썬 엔진과 같은 계산, `check_html.py`로 확인)가 하고, 이동·쓰다듬기 장면은 화면 표현입니다.
- 펫은 팀이 만든 3D 모델입니다. 구매한 에셋(GLB)은 화면의 [내 에셋(GLB) 불러오기]로 각자 PC에서만 불러오며, 파일 안에 넣거나 저장하지 않습니다(재배포 금지 조건).
- 목걸이 띠 색은 억제 강도(파랑 = 강함, 주황 = 약함), 방울 색은 경험 유지(금색 = 강함, 은색 = 약함)입니다.
- 화면 소스는 `pet3d/`에 있고, `python poc/build_html.py`로 두 HTML을 함께 다시 만듭니다. `?test=1`을 붙이면 훈련·교배·비교를 즉시 실행하는 자동 점검을 합니다.

## 가장 쉬운 실행: 파일 더블클릭

`poc/REFLEX_PoC.html`을 더블클릭하면 브라우저에서 바로 열립니다. 서버, 설치, 인터넷 연결이 필요 없습니다.

- 계산은 `static/local_engine.js`가 합니다. 파이썬 엔진(`engine.py`)을 그대로 옮긴 것이고, seed별 선택 난수도 파이썬과 같은 값을 씁니다.
- `python poc/check_html.py`로 세 조건 × seed 30개의 선택·확률·판정과 명령 해석이 파이썬과 같은지 검사합니다(Node.js 필요). 참고용 p값만 순열검정 난수가 달라 소수 셋째 자리 정도 다를 수 있습니다.
- 대화형 명령은 규칙 기반 해석기만 씁니다(브라우저 파일에 API 키를 넣지 않기 위해서). LLM 해석기는 아래 서버 실행에서만 씁니다.
- `engine.py`, 회로 데이터, `static/` 화면을 고친 뒤에는 `python poc/build_html.py`로 파일을 다시 만듭니다.
- HTML 파일은 결과를 화면에만 보여주고 파일로 저장하지 않습니다. 원자료·설정·요약 파일은 `python poc/engine.py --tag 이름`(또는 서버 실행)으로 만들고, 연구 보고서의 수치는 파이썬 엔진의 결과를 씁니다.
- 명령 해석 16문장 비교는 두 구현이 같은 명령을 내는지 본 호환성 검사입니다. 명령을 올바르게 이해하는지(계획서의 명령 해석·상태 설명 평가)는 따로 평가합니다.

## 가상 성향 교배 (genetics.py)

`engine.py` 위에 얹은 층입니다. 값과 대응표는 모두 팀 확정 전 임시값입니다(`docs/실험_확정표.md`).

- 256비트 성향 코드(16비트 칸 16개): 0번 칸 억제 강도 `g_apl`, 1번 칸 회복 속도 `decay`, 나머지 칸은 0
- 교배: 성향마다 독립적으로 부모 중 한쪽 칸을 50% 확률로 받음. 학습된 연결은 물려주지 않음
- 보상 정책: `reward_punish`(정답 보상·오답 처벌, 기본값) / `reward_only`(오답 결과 없음)
- `python poc/genetics.py --demo [--reward reward_only]`: 작은 시범 실행(seed 0–4). 본 실험은 팀이 값을 확정한 뒤 실행
- `python poc/test_genetics.py`: 기본 모드가 기준 커밋과 같은지, 코드 변환, 상속 비율, 새끼 초기화, 학습 끔 유지 등 14개 검사

## 서버 실행 (LLM 명령 해석을 쓸 때)

1. VS Code에서 이 폴더(`2026 AI contest`)를 엽니다.
2. 메뉴 **Terminal → New Terminal**을 열고, 처음 한 번만 실행합니다.
   ```bash
   pip install numpy pandas
   ```
3. 서버를 켭니다.
   ```bash
   python poc/server.py
   ```
4. 브라우저 주소창에 `http://localhost:8765` 입력 → 화면 위쪽 **다음 ▶** 버튼이나 키보드 →/← 키로 단계를 넘깁니다.
5. 끌 때는 터미널에서 `Ctrl + C`.

**단계 바로 가기**: 주소 뒤에 `?step=번호`를 붙이면 애니메이션 없이 그 단계까지 실행된 화면이 바로 뜹니다. 예: `http://localhost:8765/?step=6` (발표에서 시간이 부족하거나 화면을 캡처할 때).

LLM 명령 해석을 켜려면 `pip install anthropic`을 실행하고, 환경변수 `ANTHROPIC_API_KEY`를 설정한 뒤 서버를 다시 켭니다. 키가 없으면 규칙 기반 해석기(오프라인 데모 모드)로 동작하며, 어느 해석기를 썼는지 화면에 항상 표시됩니다.

## 7단계 구성

| 단계 | 하는 일 | 화면에 나오는 결과 |
|---|---|---|
| 1. 회로 불러오기 | 기본 조건 회로 생성 | 입력 PN 124, KC 2,597, APL 1, MBON 접근/회피(팀이 만든 두 출력) |
| 2. 자극 A·B 제시 | 두 자극의 KC 반응 계산 | A·B와 연결된 KC 240개 반응 그림, 반응 비율(기본 약 5.6%), 활동 겹침 |
| 3. 처음 학습 | A가 정답, 40회 선택 | 펫 이동, A를 고를 확률 곡선, 기준 도달 시도 수 |
| 4. 조건 변경 | B가 정답, 40회 선택 | 확률이 다시 내려가는 곡선, 재학습 시도 수 |
| 5. APL 억제 약화 | 같은 seed, APL 억제만 0.2배 | 두 조건 곡선 비교, KC 반응 그림 비교(겹침 증가) |
| 6. 30회 반복 비교 | 3조건 × seed 30 | seed별 점 그림, 평균 곡선, 도달 수·중앙값·미도달 수, 참고용 p값. 서버로 열면 `results/`에 원자료 저장(HTML 파일로 열면 저장하지 않음) |
| 7. 명령·보안 검사 | 문장 → 해석기 → 허용목록 → 실행 | 정상 명령 실행, 공격 문장 차단 기록 |

## 파일

- `engine.py` — 모델과 실험(선택·학습은 여기서만 계산). 단독 실행하면 30회 반복 결과를 출력합니다.
- `command.py` — 규칙 기반·LLM 해석기, 허용목록 검사, 상태 설명의 숫자 근거 검사
- `server.py` — 표준 라이브러리 웹 서버(API + 화면)
- `static/` — 화면(HTML·CSS·JS). 펫과 미로 그림은 팀이 직접 만든 SVG입니다.

## 시연 영상 녹화 팁

Windows **캡처 도구 → 녹화** 또는 OBS Studio로 브라우저 창을 녹화합니다. 3단계와 4단계는 "1회씩" 버튼으로 천천히 보여주고, 6단계에서 결과표를 잠깐 멈춰 설명한 뒤, 7단계에서 공격 문장 두 개가 차단되는 장면으로 마무리하면 3분 안에 끝납니다.
