# REFLEX PoC 시연 프로그램

초파리 버섯체 회로(PN → KC ⇄ APL → MBON)로 펫이 A·B 중 하나를 고르며 배우고, 조건이 바뀌면 다시 배우는 과정을 **7단계로 실행하며 결과를 보여주는** 웹 화면입니다.

> 지금 연결(시냅스)은 무작위로 만든 장난감(toy)입니다. `engine.py`의 `make_circuit()`을 FlyWire v783에서 추출한 행렬로 바꾸면 같은 화면에서 실제 회로 결과가 나옵니다.

## 실행 (Windows)

1. VS Code에서 이 폴더(`2026 AI contest`)를 엽니다.
2. 메뉴 **Terminal → New Terminal**을 열고, 처음 한 번만 실행합니다.
   ```bash
   pip install numpy
   ```
3. 서버를 켭니다.
   ```bash
   python poc/server.py
   ```
4. 브라우저 주소창에 `http://localhost:8765` 입력 → 화면 위쪽 **다음 ▶** 버튼이나 키보드 →/← 키로 단계를 넘깁니다.
5. 끌 때는 터미널에서 `Ctrl + C`.

**단계 바로 가기**: 주소 뒤에 `?step=번호`를 붙이면 애니메이션 없이 그 단계까지 실행된 화면이 바로 뜹니다. 예: `http://localhost:8765/?step=6` (발표에서 시간이 부족하거나 화면을 캡처할 때).

LLM 명령 해석을 켜려면 `pip install anthropic`을 실행하고, 환경변수 `ANTHROPIC_API_KEY`를 설정한 뒤 서버를 다시 켭니다. 키가 없으면 규칙 기반 해석기(오프라인 데모 모드)로 동작하며, 어느 해석기를 썼는지 화면에 항상 표시됩니다.

## 7단계 구성

| 단계 | 하는 일 | 화면에 나오는 결과 |
|---|---|---|
| 1. 회로 불러오기 | 기본 조건 회로 생성 | PN 50, KC 2,000, APL 1, MBON 접근/회피 |
| 2. 자극 A·B 제시 | 두 자극의 KC 반응 계산 | KC 240개 반응 그림, 반응 비율 약 9%, 겹침 |
| 3. 처음 학습 | A가 정답, 40회 선택 | 펫 이동, A를 고를 확률 곡선, 기준 도달 시도 수 |
| 4. 조건 변경 | B가 정답, 40회 선택 | 확률이 다시 내려가는 곡선, 재학습 시도 수 |
| 5. APL 억제 약화 | 같은 seed, APL 억제만 0.2배 | 두 조건 곡선 비교, KC 반응 그림 비교(겹침 증가) |
| 6. 30회 반복 비교 | 3조건 × seed 30 | seed별 점 그림, 평균 곡선, 중앙값·실패 수·p값, `results/batch_summary.csv` 저장 |
| 7. 명령·보안 검사 | 문장 → 해석기 → 허용목록 → 실행 | 정상 명령 실행, 공격 문장 차단 기록 |

## 파일

- `engine.py` — 모델과 실험(선택·학습은 여기서만 계산). 단독 실행하면 30회 반복 결과를 출력합니다.
- `command.py` — 규칙 기반·LLM 해석기, 허용목록 검사, 상태 설명의 숫자 근거 검사
- `server.py` — 표준 라이브러리 웹 서버(API + 화면)
- `static/` — 화면(HTML·CSS·JS). 펫과 미로 그림은 팀이 직접 만든 SVG입니다.

## 시연 영상 녹화 팁

Windows **캡처 도구 → 녹화** 또는 OBS Studio로 브라우저 창을 녹화합니다. 3단계와 4단계는 "1회씩" 버튼으로 천천히 보여주고, 6단계에서 결과표를 잠깐 멈춰 설명한 뒤, 7단계에서 공격 문장 두 개가 차단되는 장면으로 마무리하면 3분 안에 끝납니다.
